# Vellichor Taxonomies

本の紹介サイト「本棚に猫」（[vellichorbooks.jp](https://vellichorbooks.jp/)）のために作成した、WordPressの自作プラグインです。
通常の「投稿」に、本の情報を整理するための5つの分類（カスタムタクソノミー）を追加します。

## 追加する分類

| 分類 | 内部名 | URL | 入力方式 |
|---|---|---|---|
| 著者 | book_writer | /writer/ | 自由入力 |
| 出版社 | book_publisher | /publisher/ | 自由入力 |
| 形式 | book_format | /format/ | チェックボックス |
| ジャンル | book_genre | /genre/ | チェックボックス（親子あり） |
| 特集 | book_feature | /feature/ | チェックボックス |

## 設計で考えたこと

- **カスタム投稿タイプではなく「投稿＋分類」にした**：1冊につき1記事という運用のため、既存の記事やURLを変えずに拡張できる形を選びました。
- **内部名に `book_` を付けた**：WordPressが標準で使っている名前との衝突を避けるためです。
- **著者のURLを `/writer/` にした**：`/author/` はWordPressが投稿者の一覧ページとして使用しているためです。
- **入力方式を分けた**：著者・出版社は本ごとに増えるため自由入力に、形式・ジャンル・特集は選択肢を固定して入力の揺れを防ぐためチェックボックスにしました。
- **ラベルを関数で生成**：`vellichor_labels()` で表示名一式をまとめて作り、5つの分類で同じ記述を繰り返さないようにしました。

## インストール

1. このリポジトリのファイルを `vellichor-taxonomies` フォルダに入れてZIPにします。
2. WordPressの管理画面の「プラグイン → 新規プラグインを追加 → プラグインのアップロード」からインストールし、有効化します。
3. 「設定 → パーマリンク」で変更を保存し、新しいURLを有効にします。
